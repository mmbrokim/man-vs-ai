# Man vs AI

유튜브 쇼츠 시리즈 **Man vs AI**(사람 vs AI 경기 예측 대결)에 쓰는 코드입니다. 종목은 축구와 격투기입니다.

AI의 답은 경기 전에 SHA-256 해시로 봉인해 영상에 넣고, 결과 편에서 원문을 공개합니다.
누구나 봉인 확인 페이지에서 원문을 해시로 바꿔 영상 속 봉인값과 같은지 확인할 수 있습니다.

## 폴더 구조

| 폴더 | 내용 | 배포 |
|---|---|---|
| `public/` | 봉인 확인 페이지 (`index.html`, `app.js`, `style.css`, `seals.json`) | Vercel에 배포되는 유일한 폴더 |
| `tools/` | 봉인·집계·공개 스크립트 | 내 컴퓨터에서만 실행 |
| `model/` | 축구 예측 모델 (프리미어리그) | 내 컴퓨터에서만 실행 |
| `model_mma/` | 격투기 예측 모델 (UFC) | 내 컴퓨터에서만 실행 |
| `private/` | 봉인 원문, 유튜브 API 키 | git, Vercel 모두 올라가지 않음 |

두 모델은 데이터, 학습 코드, 저장된 모델 파일이 모두 따로입니다. 봉인·검증 도구만 같이 씁니다.

## 처음 한 번 할 일

### 설치

```bash
pip install -r model/requirements.txt    # 축구, 격투기 모델 공통
```

### 유튜브 API 키 (무료)

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 만들기
2. API 및 서비스 → 라이브러리 → **YouTube Data API v3** 사용 설정
3. 사용자 인증 정보 → API 키 만들기
4. 키를 `private/youtube_api_key.txt`에 한 줄로 저장

댓글 100개당 할당량 1을 씁니다. 기본 할당량은 하루 10,000이라 충분합니다.

### Vercel 연결

1. Vercel → Add New → Project → 이 저장소 선택
2. Framework Preset: **Other**, 나머지 설정은 그대로 (`vercel.json`이 `public/` 폴더만 배포하도록 지정합니다)
3. Deploy

이후에는 push할 때마다 자동으로 다시 배포됩니다.

## 회차 진행 순서

회차 번호는 종목과 상관없이 하나로 이어서 셉니다(EP1, EP2, …). 누적 스코어도 모든 회차를 합칩니다.
각 단계가 끝나면 `git add public && git commit -m "EP{회차} …" && git push`로 페이지에 반영합니다.

| 단계 | 시점 | 축구 | 격투기 |
|---|---|---|---|
| 1. 예측 | 경기 전 | `python model/predict.py 맨시티 풀럼 --date 2026-11-21` | `python model_mma/predict.py 페레이라 안칼라예프 --date 2026-12-07 --weight 라이트헤비급 --rounds 5` |
| 2. 봉인 | 경기 시작 전 | `python tools/seal.py --ep 1 --match "맨시티 vs 풀럼" --kickoff "2026-11-21 21:30" --answer 홈승` | `python tools/seal.py --sport mma --ep 2 --event "UFC 323" --fighter-a 페레이라 --fighter-b 안칼라예프 --kickoff "2026-12-07 12:00" --answer 1 --method 1` |
| 3. 영상 링크 | 업로드 후 | `python tools/video.py 1 https://youtube.com/shorts/xxxx` | 같음 |
| 4. 댓글 집계 | 경기 시작 직후 | `python tools/tally.py 1 https://youtube.com/shorts/xxxx` | 같음 |
| 5. 공개 | 결과 편 | `python tools/reveal.py 1 --score 2-1` (홈-원정) | `python tools/reveal.py 2 --winner 1 --method 1 --round 2` |

- 예측 전에는 `python model/fetch_data.py` 또는 `python model_mma/fetch_data.py`로 최신 기록을 받습니다.
- 봉인하면 출력된 64자리 봉인값을 영상에 넣습니다. 원문은 `private/originals.json`에만 저장됩니다.
- 격투기 번호: `--answer`/`--winner` 1 레드 코너, 2 블루 코너 (`--winner`는 3 무승부, 4 무효도 가능) · `--method` 1 KO/TKO, 2 서브미션, 3 판정
- 유튜브 API를 쓸 수 없을 때는 표 수를 직접 넣습니다.
  - 축구: `python tools/votes.py 1 --home 120 --draw 30 --away 50`
  - 격투기: `python tools/votes.py 2 --red 60 20 40 --blue 30 10 25` (각 선수의 KO/TKO, 서브미션, 판정 순)

> **주의**: `private/originals.json`은 어디에도 백업되지 않습니다. 잃어버리면 원문을 공개할 수 없으니 결과 편 전까지 지우지 마세요.
> `seal.py`는 `private/`가 git에서 제외되어 있지 않으면 실행을 멈춥니다.

## 규칙

### 봉인 원문

| 종목 | 형식 | 예시 |
|---|---|---|
| 축구 | `EP{회차}\|{답}\|{랜덤 16자}` | `EP0\|무\|ExampleOnly12345` |
| 격투기 | `EP{회차}\|{이긴 선수}\|{승리 방식}\|{랜덤 16자}` | `EP0\|선수이름\|판정\|ExampleOnly12345` |

- 축구 답: `홈승`, `무`, `원정승`
- 격투기 승리 방식: `KO/TKO`, `서브미션`, `판정`. 무승부는 선택지에 없습니다 (배팅 업체의 2-way 방식).
  선수 이름은 `seal.py`가 `seals.json`의 `fighter_a`(레드 코너), `fighter_b`(블루 코너)를 그대로 넣습니다.
- 랜덤 문자열은 가능한 답을 모두 해시로 바꿔 보는 방식으로 답을 미리 알아내는 것을 막습니다.
- 해시 계산: 앞뒤 공백 제거 → 유니코드 NFC 정규화 → UTF-8 → SHA-256.
  `public/app.js`와 `tools/common.py`가 같은 규칙을 씁니다. NFC 정규화는 Mac에서 한글 자모가 분리되는 문제를 막습니다.
- 종목은 `seals.json`의 `sport` 칸(`football`, `mma`)으로 구분합니다. 특별 경기는 `EP` 대신 `SP`로 시작합니다.

### 사람 쪽 답 (댓글 집계)

1. 최상위 댓글만 셉니다 (답글, 채널 주인 댓글 제외).
2. 경기 시작 전에 쓴 댓글만 셉니다. 시작 뒤에 수정된 댓글도 제외합니다.
3. 한 계정당 한 표. 여러 번 남겼다면 유효한 답이 있는 마지막 댓글을 셉니다. 서로 다른 답이 섞인 댓글은 무효입니다.
4. **축구**: `홈승`, `원정승`, `무`(또는 `무승부`), 두 팀 이름을 인정합니다. 팀 이름은 그 팀의 승리입니다.
   `무조건`처럼 단어 속의 '무'는 세지 않습니다.
   가장 많이 나온 답이 사람의 답이고, 동률이면 홈승 > 원정승 > 무 (실제로 더 자주 일어나는 순서).
5. **격투기**: 선수 이름(성만 써도 인정)과 승리 방식이 둘 다 있어야 유효합니다. 예) `페레이라 KO`, `안칼라예프 판정승`
   선수별 표를 합쳐 승자를 정하고(동률이면 레드 코너), 그 선수 표 중 가장 많은 방식을 고릅니다(동률이면 판정 > KO/TKO > 서브미션).
   레드 코너는 보통 더 유력한 선수로 UFC 기록상 55~60%를 이기고, 방식은 판정 47% · KO/TKO 33% · 서브미션 19% 순입니다.

집계에 쓴 댓글 ID와 선택은 `public/votes/EP{회차}.csv`로 공개합니다. 닉네임은 넣지 않습니다.

### 채점

- **축구**: 홈승 / 무 / 원정승을 맞히면 1점
- **격투기**: 승자와 승리 방식을 모두 맞혀야 1점. 결과가 무승부나 무효 경기면 그 회차는 채점하지 않습니다.

### 특별 경기

은퇴전처럼 정식 대결과 따로 다루고 싶은 경기는 **특별 경기**로 올립니다.

- 번호는 `SP1`, `SP2` …로 따로 붙고, 정식 회차 번호(EP)와 누적 스코어에는 들어가지 않습니다.
- 사람 쪽은 댓글 집계 대신 **제작자 예측**입니다. 제작자 예측은 처음부터 공개되고, AI 답은 정식 회차와 똑같이 봉인합니다.
- 페이지에는 '특별 경기' 표시와 함께 목록에 나옵니다.

```bash
# 봉인: --answer/--method 는 AI 답, --mine/--mine-method 는 제작자 예측
python tools/seal.py --special --sport mma --event "블랙컴뱃 17" --fighter-a 추성훈 --fighter-b "크리스 리벤" \
    --kickoff "2026-11-21 19:00" --answer 2 --method 1 --mine 1 --mine-method 1
python tools/video.py SP1 https://youtube.com/shorts/xxxx
python tools/reveal.py SP1 --winner 1 --method 1 --round 2
```

특별 경기는 `tally.py`, `votes.py`를 쓰지 않습니다. 원문은 `SP1|크리스 리벤|KO/TKO|랜덤`처럼 SP로 시작합니다.

## 예측 모델

두 모델 모두 **배당률을 입력값으로 쓰지 않고**, 경기 전에 알 수 있는 정보만 씁니다.
경기를 날짜순으로 지나가며 먼저 입력값을 계산하고 그다음 결과를 반영해서 미래 정보가 섞이지 않습니다.
미래 경기를 지우고 다시 계산해도 과거 경기의 입력값이 똑같은지 두 모델 모두 확인했습니다 (차이 0).

### 축구 (`model/`)

프리미어리그 기록으로 홈승 / 무 / 원정승 확률을 계산합니다. 승격팀 실력을 계산하려고 챔피언십(2부) 기록도 씁니다.

| 입력값 | 설명 |
|---|---|
| 엘로 레이팅 차이 | 경기 결과로 계속 갱신되는 팀 실력 점수의 차이 |
| 최근 5경기 승점·득실차 | 홈팀, 원정팀 각각 |
| 유효슈팅 우위 | 최근 5경기에서 상대보다 유효슈팅을 얼마나 더 했는지 |
| 홈/원정 성적 | 홈팀의 최근 홈경기, 원정팀의 최근 원정경기 승점 |
| 휴식일 | 직전 경기 후 쉰 날수 (최대 14일) |

**무승부 규칙**: 가장 높은 확률만 고르면 무를 거의 고르지 않아서, 무승부 확률이 **28% 이상이면 무**로 고릅니다.
검증 시즌에서 "전체의 5% 이상은 무를 고르는" 조건 아래 적중률이 가장 높은 값이며, 시리즈 동안 바꾸지 않습니다.

| 구분 | 시즌 | 용도 |
|---|---|---|
| 학습 | 2017-18 ~ 2023-24 | 모델 학습 |
| 검증 | 2024-25 | 모델 고르기, 무승부 기준값 정하기 |
| 시험 | 2025-26 | 마지막에 한 번만 채점 |

**2025-26 시즌 시험 결과 (380경기)**

| 방식 | 적중률 |
|---|---|
| AI (로지스틱 회귀) | 47.9% |
| 항상 홈승 | 42.6% |
| 배당률 1순위 (참고용) | 49.5% |

```bash
python model/fetch_data.py                               # 최신 경기 결과 받기
python model/train.py                                    # 학습 + 성능 시험
python model/predict.py 맨시티 풀럼 --date 2026-11-21     # 홈팀 원정팀 순서
```

### 격투기 (`model_mma/`)

UFC 기록으로 승자와 승리 방식을 예측합니다. 레드/블루 코너 정보는 쓰지 않습니다.

- **승자 모델**: 두 선수 입력값의 차이로 이길 확률을 계산합니다. 선수 순서를 바꿔 두 번 학습해 순서가 결과에 영향을 주지 않습니다.
- **방식 모델**: 이긴다면 KO/TKO, 서브미션, 판정 중 무엇일지 계산합니다. 체급과 라운드 수(3 또는 5)도 씁니다.
- 두 확률을 곱한 6가지 조합(선수 2명 × 방식 3가지) 중 가장 높은 것이 AI의 답입니다.

입력값: 엘로 레이팅(KO·서브미션 승은 더 크게 반영), 나이, 키·리치, 사우스포, UFC 경기 수, 공백 기간,
분당 유효타 적중·피격, 유효타 적중률·방어율, 테이크다운 시도·성공률·방어율, 서브미션 시도, 다운 뺏기·당하기,
KO/서브미션/판정 승·패 비율, 최근 3경기, 연승·연패. 경력이 짧은 선수는 UFC 평균값을 조금 섞어 극단값을 막습니다.

| 구분 | 기간 | 용도 |
|---|---|---|
| 학습 | 2005 ~ 2022 | 모델 학습 (그 이전 경기는 선수 기록을 쌓는 데만 씀) |
| 검증 | 2023 ~ 2024 | 모델 고르기 |
| 시험 | 2025 ~ 지금 | 마지막에 한 번만 채점 |

**시험 기간 결과 (1,013경기)**

| 방식 | 승자 적중 | 승자+방식 적중 (시리즈 점수) |
|---|---|---|
| AI (로지스틱 회귀) | 64.2% | 34.7% |
| 엘로 높은 선수 + 판정 | 55.2% | 24.9% |
| 엘로 높은 선수 + 그 선수가 가장 많이 이긴 방식 | 55.2% | 27.0% |

AI는 판정을 가장 많이 고르고(70%) 서브미션은 거의 고르지 않습니다. 서브미션이 실제로도 가장 드문 결과(17%)라서
확률이 가장 높은 답만 고르면 이렇게 됩니다.

```bash
python model_mma/fetch_data.py                   # 최신 UFC 기록 받기
python model_mma/train.py                        # 학습 + 성능 시험
python model_mma/predict.py 페레이라 안칼라예프 --date 2026-12-07 --weight 라이트헤비급 --rounds 5
python model_mma/similar.py 추성훈 리벤           # 스타일이 비슷한 선수와 스타일 맞대결 기록 (참고용)
```

**한계**: UFC 밖(원챔피언십, 베어너클, 블랙컴뱃 등) 기록은 없습니다. 마지막 UFC 경기가 3년 넘게 지난 선수는
예측 신뢰도가 낮다고 경고합니다. 45세 넘는 선수의 경기는 학습 데이터에 거의 없습니다.

자세한 수치와 입력값별 중요도는 각 모델 폴더의 `reports/`에 있습니다.
